# MSc_research_project
## Source Code

All source code used in this research is available in this repository.

- `Nighttime_light.js`: Extracts nighttime light intensity in Japan at the prefectural level.
- `prepare_data.R`: Performs data preprocessing.
- `cal_recovery_time.R`: Calculates recovery time using nighttime light data according to Algorithm 1.
- `uni_analysis.R`: Performs univariate analysis.
- `eco_boxplot.R`: Creates boxplots of economic covariates.
- `cox_.R`: Fits Cox proportional hazards models.
- `aft_.R`: Fits frequentist AFT models.
- `aft_loocv.R`: Performs leave-one-out cross-validation for frequentist AFT models.
- `bayes_1.R` and `bayes_2.R`: Fit Bayesian AFT models.
- `sim_1.R`, `sim_2.R`, and `sim_3.R`: Conduct the simulation studies.
- `competing_risk_.R`: Fits the competing-risk Fine-Gray model.
- `interval_cen2.R`, `int_bay.R`, `plot_bay.R`, and `plot_bay2.R`: Perform and visualise interval-censored survival analysis.
- `maintain.R`: Performs sensitivity analysis by substituting maintenance expenditure for disaster expenditure.
